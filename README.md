## 📝 知识添加入口

直接告诉二勇：
1. **属于哪本手册**（如"加到重卡维修手册里"）
2. **内容是什么**（文字、图片、文件都可以）
3. **放在什么分类下**（如"故障排查"、"日常保养"）

二勇会自动：
- 分类整理，结构化呈现
- 提炼要点，便于查阅
- 更新到对应手册，不搞混
- 记录更新日志

## 🔄 更新流程

1. 接收新知识 → 2. 归类整理 → 3. 提炼浓缩 → 4. 更新手册 → 5. 上线部署
